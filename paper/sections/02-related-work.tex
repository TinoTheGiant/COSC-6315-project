\section{Related Work}

Three bodies of work meet in this problem: the classical treatment of
fragmentation and allocation as a problem to be solved once, modern systems
that move data in response to the traffic they see, and the use of learning
to replace hand-written database administration.

The classical treatment is old and well understood. Fragmentation was studied
as vertical~\cite{navathe1984vertical} and horizontal partitioning of a
schema, and allocation as an optimization problem over a known workload. The
assumption running through all of it is that the workload is known in advance
and does not move. Production systems make the same assumption in a cheaper
form: consistent hashing~\cite{karger1997consistent} spreads keys evenly and
ignores geography entirely.

Systems that react to the workload came later. Schism~\cite{curino2010schism}
builds a graph of which records are accessed together and partitions it to cut
distributed transactions. Clay~\cite{serafini2016clay} detects hot records and
moves them, which addresses skew within a cluster rather than drift between
regions. Lion~\cite{lion2024} provisions replicas adaptively using a cost
model. All of these react to what has already happened. None of them learns a
policy.

The learning side has grown quickly, mostly in tuning rather than placement.
Sibyl~\cite{singh2022sibyl} learns data placement in a storage hierarchy, and
reinforcement learning has been applied to database configuration tuning. The
closest published work is RLRP~\cite{lu2022rlrp}, which uses
reinforcement learning for data placement and migration in heterogeneous
distributed storage. RLRP places objects as demand and capacity change. This
project differs in what the agent is allowed to decide: it may also split a
shard, it is judged on transactions that span several shards rather than on
single object access, and the thing it is tracking is geography rather than
capacity.

The methods used here are standard. The agent is a Deep
Q-Network~\cite{mnih2015dqn} trained with
Stable-Baselines3~\cite{raffin2021sb3}, and the structure of training in a
cheap simulator before fine-tuning on expensive real hardware is borrowed from
robotics. The contribution is therefore the measurement rather than the
machinery: what is new is a statement of when a learned policy is worth
having, with the condition measured rather than assumed.
